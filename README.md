# 押し目買いウォッチリスト

Flask版は `python app.py`、GitHub Pages向けの生成は `python generator.py`。
必要なパッケージは `pip install -r requirements.txt` でインストールします。

## TOPIXとの長期比較

`#topix` で比較タブを直接開けます。3年・5年・10年の配当再投資リターンの近似値、複利年率（CAGR）、累積リターンの差（ポイント）を表示します。

- 比較対象は **iFreeETF TOPIX（1305）** の調整済み市場価格です。配当込みTOPIX指数そのものではなく、ETF費用と市場価格の乖離が含まれます。
- 銘柄もETFも Yahoo Finance の `Adj Close` を使用。株式分割と配当を調整し、優待・個人の税金・売買手数料は含めません。
- 同じ始点日・終点日の価格を使用します。始点は各年の応当日以前の共通取引日（最大7暦日前）。年率は実際の日数 / 365.25から計算します。
- 当日の取引時間中は前日以前の確定日足を使用します。取引終了後は取得できた最新の日足を使用します。
- 上場・再上場から期間が不足する銘柄、始点・終点が一致しない銘柄、5倍超の不連続がある履歴は比較不能です。短い上場来成績を5年・10年の成績として代用しません。
- 「5年・10年とも上回る／下回る」は、それぞれ両期間の差が正／負の銘柄だけを選びます。比較不能は両方の条件から除外します。
- 従来の株価のみの比較（20営業日平均基準）と、テクニカル判定は別に表示しています。

1306には2026年3月30・31日に約10分の1の価格になる不整合があり、標準修復でも解消しなかったため、検証した1305を使用しています。取得元が全比較不能の場合は生成を中止して前回の公開ページを保ちます。

商品情報：https://www.daiwa-am.co.jp/etf/funds/5841/
