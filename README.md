# 押し目買いウォッチリスト

Flask版は `python app.py`、GitHub Pages向けの生成は `python generator.py`。
必要なパッケージは `pip install -r requirements.txt` でインストールします。

## TOPIXとの長期比較

`#topix` で比較タブを直接開けます。3年・5年・10年の配当再投資リターンの近似値、複利年率（CAGR）、累積リターンの差（ポイント）を表示します。

- 比較対象は **iFreeETF TOPIX（1305）** の調整済み市場価格です。配当込みTOPIX指数そのものではなく、ETF費用と市場価格の乖離が含まれます。
- 銘柄もETFも Yahoo Finance の `Adj Close` を使用。株式分割と配当を調整し、優待・個人の税金・売買手数料は含めません。
- 同じ始点日・終点日の価格を使用します。始点は各年の応当日以前の共通取引日（最大7暦日前）。年率は実際の日数 / 365.25から計算します。
- 当日の取引時間中は前日以前の確定日足を使用します。取引終了後は取得できた最新の日足を使用します。
- 上場・再上場から期間が不足する銘柄、始点・終点が一致しない銘柄、5倍超の不連続がある履歴は比較不能です。短い上場来成績を5年・10年の成績として代用しません。
- 「5年・10年とも上回る／下回る」は、それぞれ両期間の差が正／負の銘柄だけを選びます。比較不能は両方の条件から除外します。
- 従来の株価のみの比較（20営業日平均基準）と、テクニカル判定は別に表示しています。

## 比較時期の変更と優待の試算

- 取得する履歴は14年分。最新終点と直前35か月の月末を終点に、各回の保有期間を3・5・10年に固定して比較します。年率差の中央値・最悪・最良と、上回った回数、個々の始点・終点を表示します。
- 36期間は互いに大きく重なり、独立した試行ではありません。上回った割合は将来の勝率ではありません。
- 3・5・10年の判断期間を選択できます。上場10年未満でも、5年のデータがあれば5年フィルターの対象になります。
- 「僅差」は年率差が±1ポイント以内。「時期変更で7割以上」は36期間すべて計算でき、上回った割合が70%以上の銘柄です。履歴不足は件数を明示し、この条件から除外します。割合順の並べ替えでも36期間揃う銘柄を先に表示します。
- 優待試算は、現在株価×入力株数を初期額として、過去年率が同じ年数だけ今後も続くと仮定するシナリオです。配当は再投資、年間の優待価値は入力額を再投資せず累積します。必要年額は `max(ETFの仮定額 - 銘柄の仮定額, 0) / 年数` です。
- 優待を含む年率は、銘柄の仮定額と累計優待価値を合計して年率換算します。単純に現在の優待利回りを過去のCAGRへ足しません。
- 登録優待値は未検証の参考値で、初期状態では年間利用額を空欄にします。明示的に仮入力するボタンを設け、利用者が保有条件と実際に使う額を確認する前提です。空欄と0円を区別します。
- 入力は `yutai-topix-benefit-scenario-v1` というキーでブラウザーのlocalStorageに保存し、外部へ送信しません。保存が使えない場合も、その画面内で計算できます。
- シナリオは将来の予測でも過去の優待込み実績でもありません。過去の勝敗・フィルターは書き換えません。実際の過去リターンには各年の優待制度、保有株数、利用額の履歴が必要です。

1306には2026年3月30・31日に約10分の1の価格になる不整合があり、標準修復でも解消しなかったため、検証した1305を使用しています。取得元が全比較不能の場合は生成を中止して前回の公開ページを保ちます。
